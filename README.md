# Vendora — Multi-Vendor Marketplace Platform

## Project Overview

Vendora is a multi-vendor e-commerce platform where multiple sellers can list and manage their products, while customers can browse products from different vendors and purchase them through a unified shopping experience.

## User Roles

* **Admin:** Manages vendors, categories, platform settings, and overall platform operations.
* **Vendor:** Manages products, inventory, and assigned orders.
* **Customer:** Browses products, manages the cart, checks out, and views orders.

## Technology Stack

* **Frontend:** React.js, CSS/Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JWT, bcrypt
* **Version Control:** Git and GitHub

## Core Features

* User registration and login
* Role-based access control
* Vendor registration and approval
* Product and category management
* Product search and filtering
* Multi-vendor shopping cart
* Checkout and mock payment
* Order management
* Admin dashboard

## Project Structure

* `frontend/` — Frontend application
* `backend/` — Backend application
* `docs/` — Project flow and API documentation
