# Vendora — API Contracts

This document will define the API endpoints shared between the frontend and backend teams.

## Planned API Modules

### Authentication

* Register
* Login
* Get current user

### Vendors

* Submit vendor application
* View vendor status
* Approve or reject vendor applications (Admin)
* View vendor dashboard

### Products

* Create product
* List products
* Get product details
* Update product
* Delete product
* Search and filter products

### Cart and Checkout

* View cart
* Add item to cart
* Update item quantity
* Remove item from cart
* Checkout

### Orders

* Create order
* View customer orders
* View vendor orders
* Update fulfillment status

### Categories

* List categories
* Create, update, and delete categories (Admin)

## Important

The exact HTTP methods, endpoint paths, request fields, response formats, authorization rules, and error responses must be agreed upon by the team before implementation.
