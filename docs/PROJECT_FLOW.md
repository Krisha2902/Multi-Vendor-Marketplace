# Vendora — Project Flow

## 1. User Roles

The platform supports three roles:

* Admin
* Vendor
* Customer

## 2. Vendor Flow

Vendor Registration → Admin Approval → Vendor Dashboard → Product Management → Order Fulfillment

## 3. Customer Flow

Browse Products → Search and Filter → Add to Cart → Checkout → View Orders

## 4. Admin Flow

Admin Login → Manage Vendor Applications → Manage Categories → Monitor Platform Operations

## 5. Technical Flow

React Frontend → Express API → Application Services → Data Access Layer → MongoDB

The backend will follow Clean Architecture principles, with clear separation between business logic, controllers, and database operations.

## 6. Development Note

Detailed API contracts, database schemas, and module responsibilities will be finalized before feature development begins.
